# Cenários da campanha 2D

`tidal-observatory.png` e `last-foundry.png` são pinturas originais geradas para esta direção do projeto. O Sanctum já existente compõe o primeiro capítulo. Os três cenários deixam o piso compartilhado livre para as formações.

A animação acontece em `scripts/arena_backdrop.gd` e `shaders/stage_atmosphere.gdshader`: névoa, reflexos, calor, luz, chuva e partículas são camadas executadas pelo Godot. As imagens não contêm HUD nem personagens.
