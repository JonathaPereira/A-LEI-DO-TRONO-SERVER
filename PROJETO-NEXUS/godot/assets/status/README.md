# Ícones de estado

18 pictogramas vetoriais originais para buffs, debuffs e postura defensiva. O desenho branco recebe cor pela interface: verde para efeitos positivos, vermelho para negativos, sempre do ponto de vista do personagem que carrega o estado. A classificação usa a mesma lista do motor de combate.

A faixa inclui sinais +/−, duração, descrição em texto e inspeção por teclado. Os arquivos permanecem distintos mesmo quando dois estados compartilham uma cor. Semente e Selo astral são negativos para o alvo, pois beneficiam quem o ataca.
