M&N — frontend com somente o instalador atual · Windows 0.2.1

Esta revisão é compatível com o backend 0.13.0-alpha existente, sem SQL novo ou mudança de backend. Não repita as migrações anteriores.

1. Após o merge e o build aprovado, baixe MN-Trono-Frontend-0.2.1.zip na entrega privada mais recente.
2. Extraia numa pasta nova. frontend/downloads contém somente:
   MN-Trono-0.2.1-Windows.exe
   latest.yml
3. Entre na pasta frontend pelo Git Bash e execute:
   npx surge . a-lei-do-trono.surge.sh
4. No aplicativo instalado, clique na versão no rodapé e busque a atualização.
   Ele baixa internamente e permite reiniciar para instalar.

O EXE já vai junto do frontend. Não precisa publicá-lo em outro repositório.
O pacote contém um instalador atual e o site completo.
Confira o tamanho exato em TAMANHO-E-DOWNLOAD.json.
Preserve latest.yml e o SHA-512; não misture arquivos de entregas diferentes.
O backend 0.13.0-alpha existente é compatível. Não repita o SQL de Splendor.
A migração de Azul não precisa ser repetida se já foi aplicada.
Consulte ATUALIZAR_WINDOWS_v0.2.1.md para a ordem completa.
Consulte PUBLICAR_SURGE_LEVE.md para o passo a passo completo.
