M&N — Windows 0.1.11: catálogo de jogos e Azul

1. Faça merge do PR com Windows full app verde.
2. No Supabase SQL Editor execute upgrade-azul.sql (incluído neste pacote).
   Requer profiles/schema.sql já existente. Não repita outros SQL já aplicados.
3. Publique main no Render: backend 0.10.0-alpha, features.azul true em /health.
   Preserve as variáveis atuais; a chave de serviço continua só no backend.
4. Extraia MN-Trono-Site-com-Desktop. Entre na pasta frontend inteira, com
   index.html, games.js, azul-rules.js, downloads/ e manual/.
5. No Git Bash execute:
   npx surge . a-lei-do-trono.surge.sh
6. Confira downloads/latest.yml: version: 0.1.11.

O app instalado recebe a atualização internamente após publicar este pacote.
Clique na versão no rodapé para buscar. Reinicie quando puder encerrar a call.
Não remova latest.yml nem o instalador apontado por ele. O EXE não fica no Git.
Recordes confirmados ficam no Supabase; mesas em andamento ficam em memória.
Publique quando não houver partidas. Aguarde os recordes pendentes serem salvos.
