# Dados dos componentes

90 cartas (40/30/20 por nível) e 10 nobres do Splendor clássico. Custos, bônus e pontos transcritos dos dados factuais de game_data/cards.csv de dsmiller95/SplendorSimulator (licença MIT anexa). Origem: https://github.com/dsmiller95/SplendorSimulator/blob/main/game_data/cards.csv. Nenhum código desse motor é utilizado. Motor, interface, sons e artes desta implementação são próprios.
